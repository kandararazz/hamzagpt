# 🤖 HamzaGPT — The Funniest AI That Answers Questions With Pure Sass

> **"Ask literally anything. Prepare to get roasted."**

HamzaGPT is an ultra-modern, interactive web application that answers user questions with witty comebacks, hilarious punchlines, synthesized sound effects (Ba-Dum Tss, Sad Trombone, Airhorn, Boing), text-to-speech voice playback, and switchable roast personalities!

---

## ✨ Features

- 🎭 **6 Switchable Personalities**:
  - **😏 Hamza Special (Default)**: Witty sarcasm, clever analogies, and unexpected kernels of truth.
  - **🔥 Savage Roast**: Brutally honest comebacks guaranteed to inflict emotional damage.
  - **🎭 Dramatic Shakespeare**: Archaic Elizabethan verse turning mundane questions into cosmic tragedies.
  - **👶 Toddler Tantrum**: Pure unadulterated toddler logic, screaming, and cookie demands.
  - **👵 Overbearing Grandma**: Nagging about sweaters, eating more food, and unsolicited matchmaking.
  - **🧠 Galaxy Brain**: Absurd quantum physics, multiverse simulations, and pigeon conspiracy theories.

- 🌶️ **Roast Heat Level Slider**:
  - `Mild`: Playful sass with a warm, friendly disclaimer.
  - `Spicy`: High-grade comebacks.
  - `Nuclear`: Thermonuclear burns with zero mercy.

- 🔊 **Zero-Dependency Web Audio Soundboard**:
  - Built-in Web Audio API sound synthesizer:
    - 🥁 **Ba-Dum Tss!** (Rimshot)
    - 🎺 **Wah-Wah-Waaah** (Sad Trombone)
    - 🌀 **Boing!** (Cartoon Spring)
    - 📢 **Airhorn** (MLG Blast)
    - 👏 **Sarcastic Claps** (Applause)

- 🗣️ **Text-to-Speech (TTS Voice Out Loud)**:
  - Automatically reads responses out loud with pitch and speed tailored to each personality!
  - Individual "Listen" button on every message bubble.
  - Toggle voice on/off anytime.

- 💡 **Interactive Extras**:
  - **🎲 Random Question Generator**: Instantly fills wild and bizarre questions to test the AI.
  - **🎡 Bad Excuse Generator**: Instant excuses for escaping social obligations.
  - **📊 Chaos Statistics**: Tracks questions endured, roasts served, and brain cells lost.
  - **📋 1-Click Copy**: Copy any roast directly to share with friends.
  - **⚙️ Optional Gemini AI Mode**: Works 100% offline out-of-the-box, or you can plug in a Google Gemini API key in the settings modal for dynamic live AI generation.

## 🚀 How to Run the Website

### Option 1: Double-click to Open
Simply open `index.html` in any web browser (Chrome, Safari, Firefox, Edge). No installation or network connection needed!

### Option 2: Local Python Server (Recommended)
Run the included Python server:
```bash
python3 server.py
```
Then visit: **[http://localhost:8000](http://localhost:8000)**
